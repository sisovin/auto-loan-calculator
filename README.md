# Auto Loan Calculator

This project is an auto loan calculator that helps users calculate their monthly payments, total interest, and total payment for an auto loan. The calculator also provides an amortization table to show the breakdown of each payment.

## Features

- Calculate monthly payment, total interest, and total payment
- Display amortization table with payment breakdown
- SEO optimized content for better search engine visibility

## Setup and Installation

1. Clone the repository:
   ```
   git clone https://github.com/githubnext/workspace-blank.git
   cd workspace-blank/auto-loan-calculator
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Run the development server:
   ```
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000` to see the auto loan calculator in action.
